# Инфраструктура, разработка и правила работы

Инструменты: GitHub (основной источник версий), VS Code + Copilot, Python, Docker, Bothost, Timeweb, FFmpeg, Adobe.

## Принцип переноса между чатами
- Репозиторий — код, инструкции, decisions log, CHANGELOG, таски и конфиги **без секретов**.
- Google Диск — большие исходники, изображения, видео и архивы; сохранить имена и структуру папок.
- Для каждой версии фиксировать подтверждённый статус (проверено локально, опубликовано, требуется тест).
- Не заявлять об успешном деплое, если нет логов и проверки рабочего URL.

## Стандарт качества
Кратко, по делу. Только проверенные данные; неизвестное обозначать явно. Если не хватает сведений — назвать конкретный документ или лог, где их взять. Не придумывать факты.

## Безопасность
Никогда не фиксировать в публичном репозитории токены Telegram, WB/Ozon, API-ключи, резервные БД, договоры, частные фото, финансовые/личные данные. Для конфигураций — только имена переменных окружения и шаблоны без значений.
