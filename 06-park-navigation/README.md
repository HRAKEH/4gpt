# Навигация — парк Галицкого, Краснодар

Задача: дизайнерский плакат A3, 300 DPI, PNG, навигационная система парка.
- Палитра: хвойный зелёный вместо бордового, мягкий неоморфизм.
- Реальные карта и фотографии парка из проверяемых источников: не перерисовывать их генерацией.
- Три типа стел; интегрировать на реальные фотографии без искажения.
- Обозначения на карте A1/A2/A3 и в легенде — только стелы.
- Убрать служебные слова «концепт» и «три типа стел».
- Проверять завершённость визуальных объектов, их контакт с поверхностью и качество изображений.

Перед экспортом проверить авторство/лицензии фотографий и финальный макет.
