# «Кошкин дом» — фирменный стиль

Учебно-дизайнерский проект с утверждённым логотипом, набором вариаций, палитрой, типографикой, слоганом, паттерном, мокапами и логобуком.

## Важнейшие ограничения
- Использовать **один эталонный логотип**, максимально идентично во всех версиях и носителях; не перерисовывать самостоятельно новые контуры, если утверждён оригинал.
- Основная концепция: тёплая домашняя эстетика; шоколадный, кремовый и дополнительные цвета. Точные HEX брать из утверждённых исходников.
- Упоминался шрифт Comfortaa; полный актуальный список шрифтов сверить по исходникам.
- Слоган: «Здесь начинается путь домой».
- SVG должен быть пригоден для Illustrator; при необходимости версии в кривых.
- Небольшой фирменный паттерн (квадрат) добавить на носитель, не портя основу.
- Предпочтение реальным качественным PSD-мокапам; для исходников проверить лицензии и целостность файлов.

## Доставляемые материалы
Основной логотип и варианты SVG/PNG, палитра, набор шрифтов/названий, слоган, паттерн, 5 референсных изображений, 10 носителей с логотипом, логобук и ZIP исходников.

## Открыто
Последние диалоги отмечали расхождение формы логотипа с эталоном. Перед новыми правками **сопоставить с первоначальным утверждённым изображением 1:1**, не заявлять об исправлении без визуальной проверки.
