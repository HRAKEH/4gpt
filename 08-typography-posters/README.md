# Шрифтовые плакаты / история типографики

Сюжеты из разговоров:
- Плакат на тему Helvetica с примерами букв, сведениями об авторе и историей шрифта.
- Circular, Univers, Frutiger, Interstate, Akkurat — каждому небольшая историческая справка: автор, дата, страна, применение, реальные примеры.
- Дизайн: сильная дизайнерская композиция уровня студента старшего курса, может быть слегка под наклоном; не копировать чужой плакат 1:1.
- Использовать **реальные**, не псевдосгенерированные образцы шрифтов и источники для фактов.
- Экспорт PNG A4; фактическую доступность лицензированных шрифтов проверить.

Исторические даты и имена требует перепроверять по документированным источникам перед печатью.
