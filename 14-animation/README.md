# Анимация, After Effects, AI-видео

- Учебная задача: стилизованный огонёк — вектор Illustrator → импорт в After Effects 2024 → простое перемещение и вращение, тёмный фон, затем MP4 H.264 и сохранение редактируемого проекта.
- Анимация статичных картин и портретов: сохранить схожесть с референсом и контролировать ошибки рук/лиц.
- Разговоры об AI-video (Higgsfield и др.) для переходов, мигания логотипа и стилевых преобразований.
- Фирменный знак wxter: жидкий серебристый 3D-металл, чёрный фон, световые блики, более узкие и острые буквы; для водяного знака прозрачный фон. В других проектах использовалось имя бренда «Лазарь».

Оригиналы с изображениями людей хранить приватно; не включать их в этот публичный репозиторий.
