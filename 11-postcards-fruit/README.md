# Открытки и иллюстрации фруктов

**Открытки:** голубо-белая с нежным цветком; жёлтая с подсолнухом; китайская в бордово-чёрной гамме с вертикальными иероглифами и отдельным переводом. Запросы: умеренная детализация, меньше фотореализма, разнообразные композиции.

**Зимние ретро-фрукты:** отдельные яблоко, апельсин, ананас, гранат и другие, размер 75×109 мм; праздничная фото-иллюстративная эстетика, снежные элементы. PNG с прозрачностью там, где требуется, отдельные файлы, проверка разрешения.

Не смешивать финальные и промежуточные варианты без обозначения.
