# LandingPro — два отдельных лендинга

Продукты: «Микозацид» и «Горячий лёд». Известный GitHub-репозиторий: `HRAKEH/lendingpro`.

## Утверждённые направления
- Кинематографичные, но не перегруженные анимации в духе современных motion-landing сайтов.
- Большие кнопки WB/Ozon с корректными значками и деликатным одинаковым hover (не тряска).
- Устранение некрасивых обрезанных краёв упаковок/пикселизации; не менять графику исходных упаковок.
- ПК + мобильная адаптивность, FAQ с плавным раскрытием, улучшенное SEO.
- Мягкий неоморфизм/прозрачность, меньше искусственного визуала; без технических «01/02/03» и лишних индикаторов.
- Обсуждались GSAP/ScrollTrigger/Lenis; действительность зависимостей проверять по коду.

## Исторические версии
Были версии v7, v8/v8.1/v9; решения и загрузка в GitHub могли отличаться по состоянию чатов. Предыдущие сообщения содержали противоречивые утверждения о публикации отдельных версий. Нужна сверка с коммитами/архивами.

## Продолжение
Открыть текущий `HRAKEH/lendingpro`, сравнить макет на ПК/мобильном, сделать реальную проверку в браузере, сохранить предыдущую стабильную версию перед обновлением. Хостинг Timeweb не менять без отдельного решения.
