# Журнал про отношения и психологию

Техническое задание: **24 страницы**; первая — содержание, последняя — выходные данные (издательство, дата, тип печати, бумага и ссылки на источники). Темы: любовь, ревность, отношения, психология; русский язык и последовательное повествование.

Типографика: выключка по ширине, переносы и абзацный отступ. Пользователь отдельно обсуждал интерлиньяж 10,5–12 мм и ограничения пробелов — эти значения надо сверить с учебным заданием, поскольку мм могут быть нетипичны для такого издания.

Нужны обложка в утверждённом референсном стиле, полноценные оригинальные тексты с достоверными ссылками и качественный PDF. Перед выдачей: проверить 24 страницы, пустоты, читаемость, орфографию, переполнение и лицензии иллюстраций.
