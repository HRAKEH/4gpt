# Инструменты, организация и проверка качества

## Использовавшиеся инструменты
GitHub, VS Code + Copilot, Bothost, Docker, Python, SQLite, FFmpeg, Adobe Illustrator / After Effects, Timeweb. Рабочая среда в обсуждениях: Windows 10; оборудование — не критично для публичного архива.

## Общие правила взаимодействия
- **Только подтверждённые факты.** Не хватает данных → прямо указать, что неизвестно и откуда взять.
- Гипотезы отмечать отдельно. Не выдавать незапущенный код за протестированный.
- Ответы короткие, но с конкретными действиями. При сложном запросе — результат, а не бесконечные уточнения.
- До изменения исходников сохранять резервные копии и перечень изменяемых файлов.
- Разделять утверждённые эталоны и экспериментальные варианты.
- Документировать конфигурацию через `.env.example`, но **никогда не коммитить реальные ключи и токены**.
- GitHub как источник истины: README, структура, журнал решений, план, текущая версия, тесты и способ развертывания.
- Рендеры и макеты проверять визуально после экспорта, архивы — распаковывать и сверять состав.

## Важная граница
Публичный `4gpt` не предназначен для приватных отношений, персональных документов, переписок и исходных фотографий/видео. Содержимое закрытого Google Диска не должно автоматически попадать в GitHub.
