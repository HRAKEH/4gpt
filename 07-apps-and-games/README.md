# Мобильная игра — первая играбельная версия

**Жанр/идея:** управление поселением, жителями, производством и кухней.

## Предлагаемый MVP (проектное предложение, не согласованная реализация)
- Один небольшой участок/деревня, несколько жителей и две-три цепочки ресурсов.
- Цикл: добыча → склад → кухня/производство → обеспечение жителей.
- Управление приоритетами задач жителей, время и простая система потребностей.
- UI: ресурсы, задания, поселение, ясные состояния производства.
- Сохранение/загрузка, игровой цикл с понятной целью на 10–15 минут.

**Следующее решение:** целевая платформа Android/iOS, движок, визуальный стиль, scope первого прототипа. Игровой код пока не подтверждён.
