# «Кошкин дом» — фирменный стиль и логобук

## Зафиксированные требования
- Есть **эталонный знак из утверждённого образца**. Главный приоритет — сохранить его идентичным во всех вариантах; не менять пропорции, контуры, взаимное положение и пластику.
- Нужны векторные версии (в т. ч. SVG/Illustrator-совместимые), исходники для Illustrator и качественные PNG.
- Палитра: кремовый, шоколадный, терракотовый и сопутствующие цвета. **Точные HEX брать из исходных файлов, а не угадывать по памяти.**
- Слоган: **«Здесь начинается путь домой»** — в фирменных шрифтах и цветах.
- В чатах использовались/обсуждались Comfortaa и другие варианты шрифтов: окончательный набор устанавливать по сохранённым файлам.
- Паттерн добавить небольшим элементом к материалам логобука.
- Подобрать 5 подходящих реальных фотографий и 10 носителей; применять реальные, разрешённые к использованию PSD-мокапы.
- Подготовить полный комплект исходников для оформления брендбука ZIP + финальные PDF/SVG/PNG.

## Ошибки, на которые указывалось
- Нельзя перерисовывать эталон приблизительно, деформировать лого на мокапах, выдавать похожие версии за оригинал.
- Нужны оригинальные файлы мокапов, а не только плоские симуляции.
- Для локального файлового архива ориентиры по именам: `Koshkin_Dom_Makety_i_PSD.zip`, SVG логотипов, PDF логобука, PNG превью.
