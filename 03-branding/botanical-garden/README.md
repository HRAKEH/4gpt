# Ботанический сад — логобук 2027

- Учебная графическая айдентика и логобук ботанического сада.
- Упоминались проект `Ботанический_сад_Логобук_2027` и комплект `Praktika_BotSad_2027_Ishodniki_i_mokapy.zip`.
- Необходимо сохранять эталон логотипа и используемые шрифты/палитру, указывать форматы и реальные ссылки на исходники/мокапы.
- Итог: презентация, страницы логобука, исходники и мокапы, с проверкой содержания и совпадения с утверждённым образцом.
- Точные стандарты айдентики взять из артефактов, а не восстанавливать по воспоминаниям.
