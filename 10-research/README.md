# Исследования и поиск информации

Обсуждался выбор нейросети для медицинских исследований и чтения публикаций.

## Метод
1. Формулировать конкретный исследовательский вопрос.
2. Искать первоисточники, систематические обзоры, клинические рекомендации и метаанализы.
3. Проверять дату, дизайн, размер выборки, конечные точки, ограничения, конфликт интересов.
4. Отделять наблюдения от причинных выводов; не выдавать сгенерированные ссылки за реальные.
5. Для медицинских решений сверять актуальные рекомендации специалистов и официальных организаций.

Конкретных персональных медицинских сведений в этом публичном разделе нет.
