# Cinema Shorts — полуавтоматический видеоконвейер

Цель: Shorts/Reels для русскоязычной аудитории.

## v1
Полуавтоматические пересказы с голосом, Python + FFmpeg, проверка вручную. Предпочтение бесплатной локальной, допустимой для коммерции RU-озвучке; обсуждалась возможность собственного голоса.

## v2
Нарезка сцен из фильмов/сериалов с субтитрами и подсветкой слов, динамичный темп; рекламную плашку пользователь намеревался монтировать самостоятельно. Первый сценарий — «Джон Уик 4».

Инфраструктура: Windows 10, Xeon E5-2470 v2, Radeon RX 480, 16 GB RAM; Python 3.13/3.14, FFmpeg, VS Code, локальные каталоги Media.

**Ограничение:** кадры фильмов защищены авторским правом; наличие субтитров или рекламного блока не гарантирует право на публикацию и монетизацию. Для каждого видео проверять права и требования платформ.
