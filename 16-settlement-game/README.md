# Мобильная игра — поселение, производство и жители

Идея: управлять поселением, производственными цепочками, кухней/питанием, потребностями и задачами жителей. Упоминалось рабочее название Frosthaven.

Цель ближайшего этапа — **первая играбельная версия**, не полный коммерческий релиз. Нужно выбрать движок, целевую платформу, основной игровой цикл, минимальные ресурсы/профессии/постройки, UI и систему сохранения.

Референсом было пользовательское экранное видео. Сцены, механики и визуал необходимо сверять с оригинальным видео, если оно доступно в частном архиве.

Предпочтение: небольшие инкрементальные этапы с работающей сборкой после каждого.
