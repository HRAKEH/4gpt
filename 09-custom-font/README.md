# Собственный латинский шрифт

Проект авторского векторного шрифта из Adobe Illustrator для последующего импорта в редактор шрифтов.

Бриф развивался: коряво-рукописный → минималистичное граффити → более плавный street/handwritten → новый концепт по присланному референсу. В качестве отправной точки обсуждался Pirata One, но нужен оригинальный характер, не копия.

Символьный набор: заглавные и строчные **латинские** буквы, цифры; кириллица не нужна.
Требования: вытянутые, плавные линии, читаемость, меньше острых концов, больше рукописности. Последний референс в чате важнее старых описаний.

Пайплайн: векторные замкнутые контуры в Illustrator → масштаб и базовая линия → FontForge/Glyphs-подобный редактор (точную программу выбрать по платформе) → кернинг/пары → OTF/TTF → тесты. Настоящие исходники `.ai` и корректный файл шрифта ещё необходимо проверить.
