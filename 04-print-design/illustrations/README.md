# Учебные иллюстрации и поздравительные открытки

## Зимние фрукты
- Серия ретро-фруктов в формате 75 × 109 мм, иллюстрация на основе фотографии, но не фотореализм.
- Снег, светлый фон, чистый контур, PNG по одному объекту, желательно прозрачность при экспорте для свободного размещения.
- Примеры предметов: яблоко, апельсин, ананас, гранат, вишня и другие.

## Открытки
- Сдержанная универсальная открытка «С праздником» в нежной голубовато-белой палитре.
- Альтернативная жёлтая композиция с подсолнухом, без излишнего реализма.
- Восточная/китайская открытка — тёмно-бордово-чёрная гамма, вертикальная надпись на китайском сверху вниз с переводом; менее реалистичная, лаконичная графика.
