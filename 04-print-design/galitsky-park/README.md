# Навигация для парка Галицкого, Краснодар

- Учебный макет навигации: A3, 300 dpi, итоговый статичный PNG.
- Палитра заменена с бордового на хвойно-зелёную; аккуратный neumorphism.
- На территории должны быть **реальные фотографии и настоящая картографическая подложка**, а не сгенерированные/перерисованные подмены.
- Три вида навигационных стел, отдельный блок со стелами, точки A1/A2/A3 на карте.
- Монтаж стел в реальные фото со светом и перспективой.
- Условные обозначения: только стелы.
- Убрать технические пометы «концепт», «три типа стел»; шрифты указать в финальной работе.
- В учебном макете была персональная подпись автора — в публичном архиве она не воспроизводится.
- Факт выполнения проверять в сохранённом PNG, не полагаться на текстовое описание.
