# Временная свадебная навигация

- Два и только два шрифта: пластичный леттеринг для заголовков/имён и спокойный гротеск для остального.
- Носители: фотозона, ресторан, фуршет, смотровая площадка, церемония, приветственная вывеска молодожёнов.
- Каждый знак/табличка — отдельный PNG; ранее также запрашивались PDF и реалистичные интеграции в мокапы.
- Чистая, минималистичная типографика; пары шрифтов сочетать по характеру.
- Исходные имена персонализированных табличек не дублируются в публичном архиве без необходимости.
