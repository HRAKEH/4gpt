# Типографика, плакаты и собственный шрифт

## Шрифтовые плакаты
- Обсуждались Helvetica и сравнительный плакат про Circular, Univers, Frutiger, Interstate, Akkurat.
- Требования: краткая проверенная история каждого шрифта (автор, год, страна, применение), образцы букв и **реальные** плакаты/примеры использования, а не выдуманные.
- Компоновка учебная, выразительная, в духе дизайнерского плаката уровня старшего курса; возможна диагональная композиция.
- Достоверную информацию об авторах и датах перепроверять по типографическим источникам.

## Проект собственного шрифта
- Только латиница и цифры, **прописные и строчные**.
- Сначала ориентир Pirata One, затем смена концепции по присланному референсу.
- Направление: плавное, слегка неровное рукописное граффити/стрит, вытянутые формы, без избыточных острых углов и деталей.
- Сначала векторные контуры в Illustrator; для рабочего шрифта экспортировать глифы и метрики в шрифтовый редактор, проверить кернинг и сформировать OTF/TTF. Сам SVG-лист не является готовым устанавливаемым шрифтом.
