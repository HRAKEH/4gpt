# Cinema Shorts — конвейер коротких видео

## V1 — пересказы
- Windows 10, Python + FFmpeg, локальная полуавтоматическая подготовка с ручной проверкой.
- Нужен молодой энергичный русскоязычный голос, предпочтительно бесплатный, пригодный для коммерческого применения.
- Вопрос возможности синтеза собственного голоса; нельзя клонировать голос без права и согласия владельца.
- Обсуждались локальные директории `D:/Media/cinema_shorts_v1` и `D:/Media/ffmpeg-9.0.2`.

## V2 — кинонарезки
- Нарезки конкретных сцен с субтитрами; динамическая подсветка произносимых слов.
- Первый тестовый фильм — «Джон Уик 4»; нужно проверить сцену, подготовить сценарий монтажа и автоматическую сборку из предоставленного законного исходника.
- Баннерную рекламу пользователь намерен добавлять самостоятельно; автоматический модуль рекламы не нужен.
- **Авторское право:** наличие субтитров, эдита или баннера не гарантирует право загружать чужие кинокадры или монетизировать их. Для публикации нужен анализ прав и политики площадки.

## Технический процесс
Выбор сцены → нарезка по таймкодам → транскрипция/субтитры → оформление подсветки слов → FFmpeg-рендер → ручное QA → публикация после проверки прав.
