# Клиповые эдиты wxter — монтаж

## Творческое ТЗ из чатов
- Мрачный noir / street / кинематографический стиль с сохранением деталей и умеренной насыщенности.
- Формат приоритетно FullHD 60 fps; часть исходников 4K MOV.
- Перебивки в музыкальные акценты, флеш-переход на дропе, замедленное интро, маскирующая мозаика лица, трекинг текста за объектами.
- Без случайных повторов текста, неуместных улыбок, лишних петлей, неуместного водяного знака.
- В поздней итерации интро заменить видеовставкой, не статичным Adobe-интро.
- Использовать бесплатные инструменты и плагины там, где возможно; не искажать кадры/человека.
- Ранее использовались различные итерации `wxter_DARK_EDIT_V3/V4/V5`, `wxter_recut_project.zip` и монтажные исходники.
- Точные музыкальные тексты брать только из реально предоставленного/проверенного трека, не выдумывать.

**Неизвестно без исходников:** какая из версий окончательно утверждена, лицензии на музыку/футажи, итоговая продолжительность.
