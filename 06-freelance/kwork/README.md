# Kwork — портфолио, обложки и первые заказы

## Направления услуг
1. Карточки товаров для маркетплейсов.
2. Сайты и лендинги для бизнеса.
3. Telegram-боты на заказ.
4. Telegram-бот аналитики Wildberries/Ozon.

## Подача
- Продающие обложки с реальными примерами работ, минимальными, но читаемыми заголовками.
- Чёткий продукт и примеры, без бессмысленных псевдо-интерфейсов.
- Настоящие мокапы смартфонов, реалистичная перспектива, пропорции без деформаций.
- Для бота использовалась надпись `SellerBot` и текст «Телеграм-бот для селлеров WB и Ozon / Все магазины под контролем».
- Персональные названия магазинов в демонстрациях заменять нейтральными.
- Три понятных тарифа с границами и результатом работ.
- Не приписывать себе дипломы или профессиональный опыт, которых нет; также не строить весь профиль вокруг упоминаний нейросетей.

## Продажи
Нужны портфолио из 2–3 проверяемых кейсов, шаблоны отклика на реальные ТЗ, описание состава работ и понятные условия правок. Не использовать подозрительные платёжные схемы/заказы.
