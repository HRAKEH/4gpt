# ЗДРАВА — сайт бренда

## Исходная модель
- Статический набор HTML/CSS/JS + изображения, без обязательного этапа сборки; размещение готовой папки `public`.
- Предусматривались ссылки на карточки Wildberries/Ozon.
- Обсуждались домены `zdrava.com`, `zdrava.story`, `zdrava.ru` (на момент обсуждения последнее имя было занято; сейчас требуется проверить).
- Хостинг Timeweb: вопросы управления доменом, SSL, WHOIS privacy, прав доступа и ошибки Apache `AH00132`.

## Дизайн и контроль
- Не допускаются искажения изображений упаковки, резкие следы вырезания фона, «трясущиеся» иконки.
- Кнопки маркетплейсов: заметные, с настоящими иконками, одинаковая плавная hover-анимация небольшого увеличения.
- Умеренная графичность; осторожный неоморфизм только при сохранении читаемости.
- Убрать лишние технометки вроде 01/02/03, ненужные полосы заполнения и лишний визуальный шум.
- Исправить наводки, отступы, раскрывающиеся FAQ, анимации текста.
- Проверять размеры для телефона и ПК отдельно; улучшать метатеги, семантику, Open Graph, sitemap, изображения и Core Web Vitals.

## Критерий готовности
Один согласованный адаптивный релиз с валидными внешними ссылками, HTTPS, без горизонтального скролла и сломанной анимации.
