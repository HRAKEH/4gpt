# Публикация сайтов и инфраструктура

- Один зарегистрированный домен может обслуживать основной сайт на `example.com` и лендинг на `promo.example.com` либо по пути `example.com/promo`; необходима настройка DNS/виртуального хоста/маршрутизации.
- SSL/TLS (HTTPS) нужен для продакшена. Уточнять условия автоматического сертификата у хостинга.
- Продление домена обычно ежегодное — проверять у регистратора.
- Timeweb: при ошибках 403 и Apache `AH00132` искать права на каталоги, DocumentRoot, index, правила сервера.
- Публикацию подтверждать реальной проверкой адресов и файлов, не только заливкой ZIP.
