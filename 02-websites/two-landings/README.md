# Два независимых лендинга

- Работа начата 27 октября 2026 года.
- Предпочтение: **один приватный GitHub-репозиторий** как источник правды для кода, ТЗ, журнала решений и версий; задача переносима между чатами/аккаунтами.
- Локальный стартовый архив назывался `two-landing-workspace`; часть контекста в отдельном репозитории/архивах, которые нужно идентифицировать по фактическим файлам.
- Ориентиры: выразительные, «кинематографичные» переходы и графика, но без шаблонной чрезмерности.
- Важные исправления: отступы, качество упаковок, адаптив на desktop/mobile, иконки маркетплейсов, hover без дрожания, выразительный, но не перегруженный дизайн.
- Не переносить случайно код одного лендинга во второй. Для каждого отдельные каталоги, настройки, тесты, список URL и чеклист релиза.

**Текущая готовность:** без сверки исходного репозитория и предпросмотра не установлена.
