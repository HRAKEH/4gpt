## Политика хранения
- **GitHub — публичный**: только обезличенные технические и творческие сведения без ключей, токенов, личных переписок, финансовой первички, личных фотографий и видеозаписей.
- **Google Диск — оригиналы**: отдельная папка «выжимка, все файлы» для копий из Библиотеки ChatGPT. Текущие исходники не удаляются.
- Не путать проектные требования и подтверждённое выполнение. Незавершённое явно обозначается; версии и статусы из прошлых чатов требуют проверки.

**Ограничение:** это тематическая выжимка из доступного контекста, а не гарантированно полный дословный экспорт всех сообщений/вложений ChatGPT.
