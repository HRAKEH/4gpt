# 4gpt — архив проектов и решений

Систематизированная выжимка из **доступной** истории разговоров с ChatGPT по состоянию на 28.10.2026.

- Каждое направление находится в отдельной папке. Внутри: цель, решения, требования, текущая информация, что необходимо проверить и следующий шаг.
- Реальные файлы из Библиотеки ChatGPT копируются в **закрытую** папку Google Диска «выжимка, все файлы»; они не размещаются в этом репозитории.
- Этот репозиторий **публичный**. Личные переписки, изображения частных лиц, медицинская информация, договоры, базы заказов, API-токены, пароли и прочие секреты здесь не публикуются.
- Источник — доступные воспоминания и контекст разговоров, **не** буквальный экспорт каждого чата. Неизвестные детали обозначены как непроверенные.

## Правила продолжения работы
1. Работать только с проверенными фактами, предположения явно отмечать.
2. Не менять утверждённые логотипы, тексты, товары, геометрию без запроса.
3. Проверять экспорт, адаптивность и сохранность исходников до передачи.
4. Секреты и персональные данные хранить за пределами публичного GitHub.
