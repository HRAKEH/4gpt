# Временная навигация для свадьбы

Носители и обозначения: фотозона, ресторан, фуршет, смотровая площадка, церемония, имена молодожёнов, приветственная вывеска.

Требование: **ровно 2 шрифта** — декоративный леттеринг для заголовков/имён, спокойный без засечек для всего остального. Стиль минималистичный, согласованные пиктограммы.

Отдельные экспортные PNG/PDF и мокапы. Сверить, что все вывески имеют отдельные исходники и сохранены при архивировании.
