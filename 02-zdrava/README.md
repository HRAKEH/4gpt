# ЗДРАВА — сайт бренда

Статический сайт HTML/CSS/JS без сборки; публикация файлов из `public` на хостинге Timeweb.

Известные требования: продуктовые страницы, корректные ссылки Wildberries/Ozon, адаптивность, SEO, SSL, домен и единая айдентика. Рассматривались варианты доменов с названием zdrava; доступность и статус регистрации нужно проверять отдельно.

Прошлые проверки: синтаксис JS и якоря сайта проходили тесты, каталог зависит от JavaScript; дизайн и карточки требовали дальнейшей работы, обнаруживались отступы на планшетах/мобильных. Это исторические наблюдения, не подтверждение текущего продакшена.

**Следующее:** открыть актуальный архив и сайт, сверить тексты, изображения, торговые ссылки, responsive-брейкпоинты и метатеги. Затем проверить HTTP→HTTPS, SSL и условия домена. Не публиковать приватные данные администратора хостинга.
