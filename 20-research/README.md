# Исследования и справочные вопросы

Обсуждались: выбор AI-инструментов для поиска медицинских исследований, инструменты дизайнерской практики, домены/SSL, настройка локальных приложений, технологии видео, лицензирование ресурсов.

Принцип: по вопросам с быстро меняющейся информацией проверять актуальные официальные источники, даты, условия лицензии и ограничения использования. В медицинском поиске различать публикации, систематические обзоры, рекомендации и клинические данные; не выдавать модель за врача.
