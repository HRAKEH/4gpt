# Задания по английскому языку

Обсуждались упражнения:
- Passive Voice: Passive Simple, преобразование Active ↔ Passive.
- Past: формы to be, Past Simple и Past Continuous.
- Present Perfect: глаголы по смыслу и объяснение употребления.
- Конструкции «I have never…», рассказы о действиях, которые не выполнялись.

При решении: сохранять исходную нумерацию, давать грамматически правильные ответы и краткое объяснение правила, если это прямо указано в задании. Тексты упражнений и файлы отдельно искать в частной Библиотеке.
